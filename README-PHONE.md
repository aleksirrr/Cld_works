# Antimatter Dimensions: Endgame + Legendary (сборка для телефона)

Что внутри
- Основа: **Antimatter Dimensions: Endgame Update** (supersonic-seven), весь его контент и баланс.
- Поверх: **Legendary Edition** (krutamason): интерфейс, звук, портреты целестиалов, сайдбар, тексты и мелкие правки.
  При любом конфликте между ними побеждает Endgame.
- Добавлено для телефона: установка на главный экран (manifest) и офлайн-кэш (`public/sw.js`).

Что НЕ вошло и почему
- **Resimplified**: перестраивает игру с нуля (другая нумерация обычных челленджей, убраны автобаеры,
  переписаны глифы и Reality). С Endgame смешать безопасно нельзя. Играйте отдельно:
  https://donaldino7712.github.io/ADResimplified/
- **Space (Nitamadder Timensions)**: ~1300 конфликтных кусков с Endgame и другая версия `break_eternity`.
  Играйте отдельно: https://qwqe308.github.io/AD-Space-Mod/

Как получить ссылку для телефона
1. Создайте на GitHub пустой репозиторий и загрузите в него содержимое этой папки (нужен git или компьютер).
2. Repo -> Settings -> Pages -> Source: **GitHub Actions**.
3. Вкладка Actions -> "Build and publish to GitHub Pages" -> Run workflow (или просто push в main).
4. Через несколько минут игра откроется на https://<ваш-ник>.github.io/<репозиторий>/
5. На телефоне откройте ссылку в Chrome -> меню -> "Установить приложение" / "На главный экран".

Важно
- Сборка на момент подготовки НЕ запускалась и не тестировалась в браузере (в среде подготовки не было доступа к npm).
  Проверены только синтаксис, импорты и значения по умолчанию в сохранении. Если Actions упадёт, пришлите лог ошибки.
- Игра сделана под экран компьютера; на телефоне удобнее в горизонтальной ориентации и с зумом.
- Сохранения живут в браузере (localStorage). Регулярно делайте экспорт сохранения в настройках.
